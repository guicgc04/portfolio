Os indicadores de prazo da operação, turno a turno, com atualização automática.

Demo interativa · clique à vontade Tela cheia ↗

No celular, o painel fica melhor em tela cheia ou com o aparelho deitado.

Para que serve

O que mostra

Mostra, quase em tempo real, se cada indicador de prazo (SLA) da operação está dentro da meta, separado pelos turnos do dia. Também lista cada lote em andamento com o prazo dele.

Quem usa

Supervisores e líderes de turno, em qualquer dispositivo.

Que decisão apoia

Onde colocar gente agora, qual turno está atrasando e o que o turno anterior deixou pendente para o próximo.

Como funciona

Os dados são tratados em Python e a tela é feita em código.

  1. Um robô baixa os relatórios do sistema de gestão
  2. O ETL em Python aplica a regra de prazo de cada indicador
  3. Cada lote ganha status: no prazo, prestes a vencer ou vencido
  4. O painel recarrega os dados a cada poucos minutos

Experimente

  • Clique nos cabeçalhos da tabela para ordenar e filtrar
  • Abra a aba Lotes para ver cada lote com prazo e status, e baixe a planilha
  • Na aba Pendências por Turno, veja o que cada turno herdou, realizou e passou adiante
  • Use o botão Dia anterior para comparar com ontem
